FORMALY
________________________
Formaly is an application that helps users manage every part of Year 12 formal planning in an organised and efficient way. It brings all tasks into one place, supports different permission levels for staff and makes the entire event process easier to control from start to finish.

![Banner](Formaly.png)

Overview
________________________
Formaly is a Year 12 Software Engineering project designed to streamline the planning and management of school formal events through a centralised platform.

Features
________________________
    Role based login system
    Task management
    Budget tracking
    Venue management
    Attendance system
    Report generation
    
Technologies
________________________
    Python
    Tkinter
    SQLite

User Roles
________________________
    Admin
    Planner
    Support Staff
    Attendee
